# מסלול IMPACT

> Move · Connect · Impact — הופכים פעילות אישית להשפעה משותפת

React + Vite app implementing the mobile screens from [PRODUCT_SPEC.md](./PRODUCT_SPEC.md): splash, onboarding, home, challenges, group, and impact.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds and publishes to GitHub Pages automatically via [.github/workflows/deploy.yml](./.github/workflows/deploy.yml).
